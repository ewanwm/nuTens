inline virtual void setMasses(Tensor &newMasses)

Set the masses corresponding to the vacuum hamiltonian eigenstates.

Parameters:

newMasses – The new masses to use. This tensor is expected to have a batch dimension + 1 more dimensions of size nGenerations. The batch dimension can (and probably should) be 1 and it will be broadcast to match the batch dimension of the energies supplied to calculateProbs(). So dimension should be {1, nGenerations}.
